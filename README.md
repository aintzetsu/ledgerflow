# LedgerFlow — SaaS Revenue & Cashflow Analytics

Interactive B2B fintech analytics dashboard built with modular HTML5, CSS3, HTML5 Canvas charting, and Vanilla JavaScript.

## Features
- Interactive time-range (`3M`, `6M`, `12M`) and plan-tier segment filters updating KPIs, charts, and ledgers
- HiDPI Canvas Revenue vs. Expenses chart with live pointer hover crosshairs and tooltips
- Searchable, sortable invoice ledger with `localStorage` persistence, manual invoice entry modal, and CSV export
- `Ctrl+K` quick-action command palette and Light/Dark mode toggle
